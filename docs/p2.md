# P2 강의 자료 (RAG · Vector Store · Evaluation)

## 핵심 개념 정리
- RAG 프롬프트: “context를 근거로 question에 답하라”는 틀을 PromptTemplate/ChatPromptTemplate로 정의(@P2.md 1-26). Retriever 출력과 질문을 모두 체인에 흘려보내는 구조를 표준화한다.
- Retriever 체인 합성: `{ "context": retriever, "question": RunnablePassthrough() } | prompt | llm` 패턴으로 검색→프롬프트→LLM을 한 파이프라인으로 묶는다(`P2/2-rag.py`, `P2/11-rag.py`).
- Vector Store: 임베딩(`GoogleGenerativeAIEmbeddings`/`HuggingFaceEmbeddings`)으로 텍스트를 벡터화하고 `InMemoryVectorStore`나 `Chroma`에 적재 후 `as_retriever()`로 검색(`P2/10-vectorstore.py`, `P2/14-rag.py`).
- 재랭크/압축: CrossEncoder 기반 `ContextualCompressionRetriever`로 검색 결과를 재정렬·축약해 정밀도를 높인다(`P2/10-vectorstore.py`, `P2/11-rag.py`).
- 로더/스플리터: Web/PDF/Markdown 로더 후 `RecursiveCharacterTextSplitter`나 `MarkdownHeaderTextSplitter`로 청크 분할 → RAG 입력 품질 확보(`P2/6-pdf.py`, `P2/7-md_splitter.py`).
- 평가: ragas `TestsetGenerator`로 synthetic QA 세트 생성 후 LangSmith dataset으로 업로드(`P2/17-ragas.py`, `P2/18-dataset.py`), `langsmith.evaluation.evaluate`로 QA/criteria/embedding-distance 평가(`P2/19-evaluation.py`).

## 실행 준비
- venv 권장: `python -m venv .venv && .venv\Scripts\activate`
- 필수 패키지 예: `pip install -U langchain-google-genai langchain-community langchain-text-splitters langchain-chroma langchain-huggingface ragas langsmith python-dotenv`
- 환경변수: `.env`에 `GOOGLE_API_KEY`, `LANGCHAIN_TRACING_V2`, `LANGCHAIN_API_KEY`(LangSmith), 필요 시 `HUGGINGFACEHUB_API_TOKEN`

## RAG 프롬프트와 체인 패턴
- 간단 RAG 프롬프트 정의와 체인 합성:

```1:34:P2/2-rag.py
prompt = PromptTemplate.from_template("다음 context를 근거로 질문에 답하세요.\ncontext: {context}\nquestion: {question}")

```

## Retriever·Vector Store 기본

## 실습 포인트
- 프롬프트/체인: `RunnablePassthrough`와 retriever 매핑으로 RAG 파이프라인을 표준화해보기.

- 메타데이터/필터: Chroma 필터 검색과 SelfQueryRetriever로 구조화 필터를 자동 생성해보기.
- 평가: ragas로 생성한 테스트셋을 LangSmith로 올려 QA/criteria/embedding-distance 지표 확인.
