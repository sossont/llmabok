## RAG

- LLM은 사전에 학습시킨 모델이기 때문에 최신 내용은 포함되어있지않음 -> 대통령을 물어봐도 윤석열이 나옴
- Context를 prompt 에 적어주면 답변을 정교하게 만들 수 있음.
- RAG는 RAG Chain 과 RAG Prompt 두 가지만 기억하면 된다.
- 문서 읽을 때 인덱싱 과 retrieval 진행
- Web에서 읽어오거나, 문서 읽거나
- Web용은 WebBaseLoader, Pdf 문서읽는거는 PyPDFLoader 이용해서 읽어오기

문서를 자를 때, 문서를 어떻게 자를 것인지? -> LLM에게 문서를 주고 정보 추출하라고 시킴 -> 그리고 나서 DB에 저장 진행 
어떤 정보를 추출해서 Vector DB에 넣을 것인지 어떻게 판단 ? -> LLM에게 주고 답을 물어보면 된다.

AI에게 Prompting을 물어보는 것도 매우 좋음. 페르소나 같은 것을 지정할때도 AI를 활용하면 좋다. 이런걸 AI 활용을 해야 생산성이 올라감.
입력 예시, 출력 예시를 구체적으로 주는 것도 좋음.

- Bi-Encoder와 Cross-Encoder. 많은 양의 문서가 있을 때는 우선 Bi-Encoder를 사용하고, 그 내용에서 랭킹을 매긴다음, 그 순위 내에서 Cross-Encoder로 랭킹을 다시 집계함.
- 현재는 기본으로 Langchain에 구현되어있는 InmemoryDB를 사용했는데, Langchain과 연동이 되는 vector db들이 많이 있음.
- InMemoryDB는 학습용으로 만든거고, 실용적으로 사용하려면 Chroma DB를 사용하는 것이 좋음
