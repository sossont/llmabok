## SSL 오류 발생시

1. 네트워크 설정에서 프록시 없애기
2. pip install pip_system_certs 모듈 설치 후에
set NO_PROXY=localhost,127.0.0.1,::1
set HTTPS_PROXY=  
set HTTP_PROXY=

이렇게 3개 환경변수 변경해주면된다.

## 프롬프트 템플릿화

프롬프트 공유 사이트 : https://smith.langchain.com/hub

- Langchain은 프롬프트 템플릿을 잘 만들고 공유하고 활용하게 되어있음
- chain의 장점 -> propmt, llm, output parser 모두 활용가능.
- Runnerable이라는 객체를 활용
- Python Runnable Lambda : Runnable을 상속해서 Lambda로 사용하는 것

- PromptTemplate : 텍스트 템프릿을 정의하고 {변수}로 자리를 채운다. LLM 호출 전 단계로 사용
  - MessagesPlaceholder : 단일 문자열이 아니라 메세지 목록을 그대로 삽입할 때 사용함

RAG 프롬프트가 뭔지만 알면 잘 사용할 수 있음
프롬프트 템플릿 등은 공개도 많이 되고 자료가 많기 때문에 활용하기가 용이함

-----------------------------------------------------

OutputParser 사용 시, Pydantic으로 응답 타입 처리할 때, prompt에 json 형식으로 어떻게 출력이 필요한지 프롬프트를 같이 넣어줘야 Class 타입으로 처리할 수 있음.
안 그러면 처리가 불가능함.
아니면 get_format_instructions 를 이용해도 된다 .

JsonOutputParser, PydanticOutputParser 이렇게 2가지가 있는데, json 파일로 출력을 받고 싶을때는 JsonOutputParser를 사용하는 것이 더 좋을수도 있음.
자연어로 Output을 받으면 곤란하고, 프로그램에서 원하는 output으로 파싱을 해야하는데, 이거는 반드시 프롬프트에 명시해서 요청을 해야한다.
출력에 관한 형식을 프롬프트에서 명시해야함.
그리고 형식은 현재까지는 json 방식으로 하는 게 제일 효율적임.
